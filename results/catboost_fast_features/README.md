# CatBoost с тремя дополнительными признаками

Обучены четыре варианта: Motion + HR + Clock/Cosine, с тремя быстрыми признаками и без них. Дополнительные признаки: пик движения за эпоху, доля активных пятисекундных отрезков за минуту, относительный пульс.

## Протокол

31 участник, 25 481 эпоха. Leave-one-subject-out: каждый участник предсказывается моделью, обученной на остальных 30. Всего 124 обучения для оценки и ещё четыре обучения на всех участниках для сохранения весов. Порог P(сон) = 0,5; предсказания не сглаживаются.

Использована текущая конфигурация репозитория FAST=True: 100 деревьев, глубина 4, learning_rate=0,1, l2_leaf_reg=3, random_seed=0, веса классов balanced. Это полная проверка на 31 участнике с фиксированными параметрами; расширенного поиска гиперпараметров нет.

## Метрики по объединённым тестовым эпохам

| Время | Признаки | AUC | κ при 0,5 |
|---|---|---:|---:|
| Clock | Исходные | 0.880 | 0.357 |
| Clock | +3 быстрых | 0.890 | 0.389 |
| Cosine | Исходные | 0.877 | 0.361 |
| Cosine | +3 быстрых | 0.885 | 0.393 |

## Средние метрики по участникам

| Набор | AUC | κ при 0,5 |
|---|---:|---:|
| Motion, HR, Clock | 0.912 | 0.377 |
| Motion, HR, Clock + быстрые | 0.922 | 0.409 |
| Motion, HR, Cosine | 0.907 | 0.380 |
| Motion, HR, Cosine + быстрые | 0.918 | 0.406 |

Добавление признаков улучшило AUC и κ по объединённым эпохам для обоих вариантов времени. Эти цифры нельзя напрямую сравнивать с прежним MLP: там были пять внешних разбиений и средние по участникам. Для честного сравнения CatBoost и MLP нужны совпадающие модели, разбиения и способ усреднения.

Показатели при чувствительности ко сну 90% в results.csv и на рисунке — описательный анализ с выбором порога по истинным тестовым меткам, как в таблицах статьи. Это не качество заранее выбранного порога.

Clock — циркадный признак из репозитория, Cosine — временная косинусоида. Цветовое отрицание clock на прежних SHAP-графиках не применяется к входам модели. Окна и медиана записи используют будущие данные. Выборка уже использовалась в других экспериментах, нужна внешняя проверка.

## Использование весов

```python
from catboost import CatBoostClassifier
model = CatBoostClassifier()
model.load_model("results/catboost_fast_features/catboost_cosine_fast.cbm")
# X: motion, hr, cosine, peak, active, hr_rel — именно в таком порядке.
p_sleep = model.predict_proba(X)[:, 1]
sleep = p_sleep >= 0.5
```

Порядок признаков и параметры каждой модели записаны в соседнем JSON. Финальные веса не использовались для оценки качества.
