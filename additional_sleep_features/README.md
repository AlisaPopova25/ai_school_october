# Три дополнительных признака для MLP

`additional_sleep_features.py` — самостоятельный Python-файл. Зависит только от NumPy, не требует исходного проекта, весов модели или разметки сна. Численная часть перенесена из функции `make_fast_features`, использованной для обучения нашего MLP с шестью входами.

## Установка и запуск

```bash
pip install -r requirements.txt
python additional_sleep_features.py --motion motion.csv --heart-rate hr.csv --epochs epochs.csv --output additional_features.csv
```

CSV может содержать одну строку заголовка или быть без заголовка. Также поддерживаются текстовые файлы с пробельными разделителями.

**Обрабатывайте отдельно каждого участника и каждую запись.** Все временные метки должны быть в секундах и иметь одно начало отсчёта: либо Unix time во всех файлах, либо относительное время во всех файлах. Скрипт сам не переводит часовые пояса и не совмещает часы приборов.

## Вход

| Файл | Столбцы | Единицы |
|---|---|---|
| `motion.csv` | `timestamp,x,y,z` | Время: секунды; ускорение: **g** |
| `hr.csv` | `timestamp,heart_rate` | Время: секунды; пульс: **bpm** |
| `epochs.csv` | `timestamp` | Начало каждой допустимой 30-секундной эпохи |

Числовые данные должны быть конечными, отсортированными по времени. Пульс должен быть положительным. Очистку артефактов и выбор допустимых эпох следует сделать до вызова. Ускорение в м/с² предварительно делится на 9,80665; не применяйте этот перевод к данным, уже записанным в g.

## Выход и формулы

Выходной CSV содержит время начала эпохи и три столбца **в порядке, ожидаемом нашим расширенным MLP**:

1. `log_peak_5sec_movement`: пик движения внутри эпохи, `log1p(max(m) / 0.02)`.
2. `active_5sec_fraction_1min`: число доступных пятисекундных отрезков с `m >= 0.02`, делённое на число доступных отрезков в минутном окне.
3. `relative_mean_hr_1min`: `(средний пульс за минуту - медиана пульса записи) / медиана пульса записи`.

Для каждого пятисекундного отрезка `m = sqrt(var(x) + var(y) + var(z))`; дисперсии считаются с делением на N, как `numpy.var(..., ddof=0)`. Это колебания ускорения относительно среднего данного отрезка.

Минутное окно относительно начала эпохи t: `[t - 15, t + 45)`. В нём 12 пятисекундных отрезков; центральные шесть соответствуют текущей эпохе. Отрезок доступен при наличии не менее двух измерений ускорения. На краях непрерывных последовательностей эпох окна обрезаются; разрывы между эпохами не пересекаются.

Средний пульс — арифметическое среднее наблюдавшихся измерений, без интерполяции. Медиана рассчитывается по всему переданному массиву пульса. Если нет доступного отрезка движения внутри эпохи или нет измерений пульса в её минутном окне, функция выдаёт ошибку.

Рядом сохраняется `additional_features.metadata.json` с порогом, медианой пульса и параметрами окон. Чтобы воспроизвести наши обученные веса, сохраняйте порог **0.02 g**.

## Использование в Python

```python
from additional_sleep_features import make_fast_features, FAST_NAMES

# motion.shape == (N, 4): timestamp, x, y, z
# heart_rate.shape == (M, 2): timestamp, bpm
# epoch_times.shape == (K,): начало каждой допустимой эпохи
extra, metadata = make_fast_features(motion, heart_rate, epoch_times)

# base — исходные count, HR statistic, cosine для тех же эпох, в том же порядке.
import numpy as np
mlp_inputs = np.column_stack([base, extra])  # шесть входов
```

Скрипт рассчитывает только дополнительные признаки. Исходные три признака, обучение и предсказание в него не включены.

## Временной контекст

Окно использует будущие измерения, а медиана пульса — всю запись. Это обработка готовой записи. Значения истинных классов не используются. Признак clock/cosine в этом модуле не рассчитывается и не меняется.
